# 安全政策 / Security Policy

## 中文

### 支持版本

仅最新 GitHub Release 版本接受安全修复。旧版本可能包含已经修复的问题。

### 报告安全问题

请使用 GitHub 仓库的 **Security → Report a vulnerability** 私密报告功能。请勿在公开 Issue 中发布漏洞利用步骤、个人数据、账号信息、Cookie、申请资料、ntfy 主题或其他秘密。

报告中请包含受影响版本、复现步骤、预期行为、实际行为和影响范围。维护者不会要求提供 Amex 登录凭据、信用卡资料或申请表内容。

### 范围

可以报告扩展权限滥用、意外数据传输、跨站脚本、代码注入、通知泄露、错误的标签页或窗口操作等问题。American Express、Google Chrome、ntfy 或其他第三方服务本身的问题不属于本项目的安全范围，应报告给相应服务提供者。

## English

### Supported versions

Only the latest GitHub Release is supported for security fixes. Older versions may contain issues that have already been corrected.

### Reporting a vulnerability

Use the repository's private **Security → Report a vulnerability** feature. Do not publish exploit steps, personal data, account information, cookies, application data, ntfy topics, or other secrets in a public issue.

Include the affected version, reproduction steps, expected behavior, actual behavior, and impact. The maintainer will never request Amex credentials, card information, or application-form contents.

### Scope

Reports may cover permission misuse, unintended data transmission, cross-site scripting, code injection, notification leakage, or incorrect tab/window operations. Vulnerabilities in American Express, Google Chrome, ntfy, or another third-party service are outside this project's scope and should be reported to the applicable provider.
